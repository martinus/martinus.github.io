Wichteln

Trag alle Namen ein und lose aus. Danach bekommt jede Person einen eigenen, geheimen Link.

    „Zieht nicht“ ist die Ausnahme. Bei einem Paar trägt die Seite sie auch bei der zweiten Person ein. Du kannst das ändern.

    Gleiche Namen, gleiche Ausnahmen und gleicher Code ergeben immer dieselbe Ziehung. Trag einen alten Code ein, um eine Ziehung zurückzuholen. Behalte den Code für dich.

    Ausgelost

    Schick jeder Person ihren Link. Öffne nur deinen eigenen Link, sonst weißt du, wer wen beschenkt.

      Wie geheim ist das?
      • Die Seite hat keinen Server. Dein Browser lost aus. Die Namen verlassen dein Gerät nur in den Links, die du verschickst.
      • Jeder Link enthält genau ein Ergebnis. Es ist unleserlich verpackt, aber nicht verschlüsselt.
      • Wer einen Link öffnet, sieht das Ergebnis. Schick jeden Link nur an die richtige Person.
      • Alle Zettel einer Ziehung zeigen dieselbe Kennung. So erkennt ihr einen alten Link.
      • Wer die Namen, die Ausnahmen und deinen Code kennt, kann die Ziehung nachrechnen. Darum bleibt der Code bei dir.
      • WhatsApp sieht die Nachricht mit dem Link wie jede andere Nachricht.

      Dein Zettel liegt im Sack. Achte darauf, dass dir niemand über die Schulter schaut.
